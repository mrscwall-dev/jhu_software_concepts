Lynn Wall Professional Portfolio

Description:
This project is a multi-page professional portfolio created with Python,
Flask, Blueprints, HTML, and CSS.

Requirements:
Python 3.10 or newer

Setup Instructions:
1. Create a virtual environment:
   python3 -m venv venv

2. Activate the virtual environment:
   source venv/bin/activate

3. Install the required dependency:
   python -m pip install -r requirements.txt

Run Instructions:
1. From the module_1 folder, run:
   python run.py

2. Open this address in a web browser:
   http://localhost:8080

Pages:
- Home
- Contact
- Projects & Publications
